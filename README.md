# BugunAL

Сервис продажи излишков еды со скидкой с самовывозом в Бишкеке.
Java 17, Spring Boot 3.4, PostgreSQL, Flyway, Spring Security и серверные страницы Thymeleaf.

## Запуск

Настройте переменные из `.env.example` (БД, SMTP и начального администратора).
Запустите PostgreSQL, затем `scripts/start-backend.ps1` либо `./mvnw.cmd spring-boot:run`.
Интерфейс: [localhost:8080](http://localhost:8080).
Скрипт PowerShell читает локальный `.env`; при прямом запуске Maven переменные должны быть заданы в окружении.

Отдельная сборка фронтенда не нужна: шаблоны и ресурсы включены в приложение.
Для совместимости `npm run dev` в `frontend` проксирует приложение на порт 5173.

## Страницы первого этапа UI

- `/` — главная, поиск, фильтры по типу заведения, цене и времени, сортировка.
- `/profile` — профиль каждой из трёх ролей, имя, телефон, смена пароля, e-mail и 2FA.
- `/seller` — кабинет сотрудника со сведениями только о своём заведении.
- `/admin` — панель администратора: поиск и фильтры пользователей, блокировка с подтверждением, создание заведений и сотрудников.
- `/login`, `/register`, `/forgot` — существующие сценарии авторизации.

Права проверяет Spring Security. При временном пароле сотрудник перенаправляется в профиль.
При смене пароля, e-mail и 2FA действующая сессия завершается.

Внешний вид основан на Figma TakeToday; название, роли, уведомления только по e-mail и фильтры адаптированы к ТЗ BugunAL.
Изображения и SVG сохранены локально в `src/main/resources/static/assets`.
В макете главная представлена на мобильном экране; на компьютере карточки складываются в сетку.

## Предпросмотр карточек

Установите `UI_DEMO=true` перед запуском, чтобы увидеть примеры наборов из Figma.
Режим явно подписан на странице, не создаёт пользователей и заказов и не позволяет покупать демонстрационные наборы.
По умолчанию он выключен: главная показывает пустое состояние, поскольку модуль предложений пока не реализован.
Заказы, оплаты, выдача, полные сведения о заведении и статистика относятся к следующим этапам.
Значения статистики не подменяются демонстрационными числами.
Существующий API регистрации работает с Gmail и кодом подтверждения; восстановление по ссылке из ТЗ ещё не реализовано.

## Проверка

`./mvnw.cmd test` — тесты API, шаблонов, поиска и доступа по ролям.
`npm run check --prefix frontend` — синтаксис клиентских модулей.
