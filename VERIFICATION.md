# Результаты проверки

## UI по Figma — актуальная проверка 20 октября 2026

- Spring Boot **3.4.13**, Java 21 с компиляцией под Java 17, тестовая БД H2 в режиме PostgreSQL.
- `mvnw.cmd test -DforkCount=0`: **17 tests, 0 failures, 0 errors, 0 skipped**.
- Для JVM в этой среде заданы `MAVEN_OPTS=-Xmx256m -XX:MaxMetaspaceSize=192m -XX:ReservedCodeCacheSize=48m -XX:+UseSerialGC`.
- Mockito использует `mock-maker-subclass`: тесты подменяют интерфейс почтовой службы без динамического подключения Java-агента.
- `npm run check --prefix frontend` и `git diff --check`: успешно.
- Проверены серверные шаблоны главной, профиля всех ролей, кабинета заведения и панели администратора; экранирование пользовательского имени; поиск по составу, цене, типу и времени; доступ по ролям; обязательная смена временного пароля.
- Сохранены регрессионные тесты авторизации, CSRF, блокировки и создания сотрудников.
- Используемые PNG и SVG из Figma скачаны в проект и проверены на наличие и ненулевой размер. В шаблонах нет временных адресов Figma.
- Визуальная проверка в браузере не выполнена: доступных браузеров в подключённой среде нет. Соответствие геометрии и переполнение на реальных устройствах требуют проверки.
- Реальная доставка почты и работа с PostgreSQL в этой проверке не выполнялись.
- Модуль предложений и заказов отсутствует: карточки доступны с `UI_DEMO=true`; без него каталог пустой, статистика помечена как недоступная.

Для исполнения Java-тестов использовались доступные локально зависимости **Spring Boot 3.5.6**, Java 21 с `--release 17`, H2 2.3.232 и подменённый JavaMailSender. Основной `pom.xml` сохраняет требуемую ветку **3.4**, версия **3.4.13**. Временный `pom.verify.xml`, кеш `.verify/` и результаты в `target/` исключены из Git и не относятся к исходникам приложения.

В этой песочнице JDK выдаёт `AccessDeniedException` при закрытии некоторых JAR через ZIP filesystem. Классы были скомпилированы напрямую `javac`, после чего тесты реально исполнены через Maven Surefire. Итог Surefire: **12 tests, 0 failures, 0 errors, 0 skipped**. Это проверка сценариев на указанных локальных зависимостях; перед сдачей требуется обычный `mvn test` на целевой версии и проверка с PostgreSQL и настроенным SMTP.

Проверены: создание покупателя только после кода, запрет повторного использования кода, срок и лимит попыток, аннулирование старого кода при новой отправке, отказ при сбое SMTP, Gmail и пароль, блокировка после пяти неверных паролей, восстановление и завершение старых сессий, добровольная 2FA, доступ по ролям, CSRF, блокировка пользователя, запрет самоблокировки администратора, создание заведения и сотрудника, обязательная смена временного пароля, смена Gmail с текущим паролем и подтверждением нового адреса.
